# Medrese SMS

A modern School Management System for Islamic secondary schools — built with **React**, **JavaScript**, **Tailwind CSS**, and **Vite**.

## Features

- Role-based dashboards for 7 user types (Director, Secretary, Cashier, Teacher, Educator, Student, Boarding Student)
- Student management, finance/payments, attendance, dormitory, discipline, and extracurricular modules
- Dark-first UI matching the design specification
- Demo login accounts for every role

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) and sign in with any demo account (password: `demo123`).
